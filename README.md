🌱 eYantra CropDrop Bot (CB) – 2025-26

This repository contains the implementation of tasks completed as part of the e-Yantra Robotics Competition (eYRC) 2025-26, under the CropDrop Bot (CB) theme.

The project focuses on designing and programming an autonomous robotic system capable of performing precision agricultural tasks such as navigation, detection, and crop handling.

🚀 Project Overview
![cropdrop bot](https://github.com/user-attachments/assets/993b733c-fa0c-4967-b6f5-6e2305c740da)

The CropDrop Bot theme is centered around automation in agriculture, where a robot is required to:

Navigate through a structured arena
Detect objects/crops using sensors or vision
Pick and place (drop) items at designated locations
Perform tasks autonomously with high accuracy

This aligns with real-world robotics applications in smart farming and precision agriculture.

🧠 Key Learnings
Embedded Systems Programming (STM32 / Arduino)
PID Control for Line Following & Motion Stability
Sensor Integration & Calibration
Autonomous Navigation Logic
Debugging & Real-time System Optimization
